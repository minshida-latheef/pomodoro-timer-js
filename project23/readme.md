\# ZenPulse ⏱️



A sleek, dark-mode Pomodoro focus timer built with vanilla HTML, CSS, and JavaScript to help you stay productive.



\## Features

\- \*\*Preset Modes:\*\* Quickly switch between Focus (25m), Short Break (5m), and Long Break (15m).

\- \*\*Live Tab Countdown:\*\* Displays the remaining time directly in your browser tab title.

\- \*\*Smooth Typography:\*\* Uses tabular numbers (`tabular-nums`) so digits stay aligned without jittering.

\- \*\*Simple Controls:\*\* Start, pause, and reset your session with a single click.



\## Getting Started

1\. Clone or download this repository.

2\. Open `index.html` in any web browser.



\## Tech Stack

\- HTML5

\- CSS3 (Flexbox \& Dark Theme UI)

\- Vanilla JavaScript (Timers \& DOM Manipulation)
